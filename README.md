# Linux Network Security Lab

## About the Project

I created this project to improve my Linux, networking, and security skills through hands-on practice.

The goal is to build a small lab environment consisting of two virtual machines:

* A Linux server that I configure, secure, and manage
* A client machine used to test connections, services, and security configurations

This repository documents my learning journey, including the labs I complete, the problems I encounter, the solutions I find, and the lessons I learn along the way.

---

## Skills I Want to Develop

### Security

* Installing and configuring a Linux server
* Managing users and permissions
* Setting up SSH access
* Configuring a firewall with UFW
* Applying basic server hardening
* Monitoring logs and detecting suspicious activity

### Networking

* Connecting virtual machines in a shared network
* Understanding IP addresses, ports, and network services
* Testing connectivity using tools such as `ping` and `ssh`
* Understanding TCP, UDP, and common network protocols

### Troubleshooting

* Finding and fixing configuration issues
* Reading and analyzing system logs
* Testing and verifying solutions
* Documenting problems and resolutions
