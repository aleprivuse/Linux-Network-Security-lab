# Linux Network Security Lab
## About the Project
I created this project to improve my Linux, networking, and security skills.
My goal is to build a small lab environment with two virtual machines:
- A Linux server that I will configure, secure, and manage
- A client machine that I will use to test connections and services
This project is still a work in progress, and I will document my progress, mistakes, and what I learn along the way.
---
## Skills I Want to Develop
### Security
- Installing and configuring a Linux server
- Managing users and permissions
- Setting up SSH access
- Configuring a firewall (UFW)
- Applying basic server hardening
### Networking
- Connecting two virtual machines in a private network
- Understanding IP addresses, ports, and services
- Testing connectivity with tools like ping and SSH
### Troubleshooting
- Finding and fixing configuration problems
- Reading system logs
- Testing and verifying solutions
